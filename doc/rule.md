# VAJRAX: Product & UX Golden Rules

This document defines the unshakeable laws of VAJRAX. Every design decision and feature implementation must pass these rules before shipping.

---

## 1. The Core Philosophy Rules
1. **Direction Over Motivation**: "Choose the life you want to build. VAJRAX turns it into today's actions." Universal loop: `Direction → Principles → System → Today → Action → Evidence → Reflection → Adaptation`.
2. **Progressive Autonomy**: The ultimate goal of VAJRAX is to build self-direction. It guides beginners, suggests to intermediates, and quietly reflects for masters.
3. **Zero Nagging**: VAJRAX never competes for attention. Notifications are silent by default, strictly contextual, and never use guilt or manipulation (no "We miss you" or "Streak lost").
4. **Proof, Not Points**: Progress is demonstrated through real evidence and principle strength, not gamified XP, levels, or streak flame emojis.
5. **Behavior ≠ Motivation**: When an action is missed, the system treats it as a structural friction issue (timing, environment, workload), never a character flaw.

---

## 2. The UX Golden Rules

### Rule 1: The Single-Core Principle (NOW / NEXT / LATER)
- The home screen never overwhelms with a 12-item flat checklist.
- Visual attention is fixed on **NOW** (the current active focus card).
- Upcoming items are categorized cleanly into **NEXT** and **LATER**.
- 1-tap start and 1-tap instant completion eliminate all friction.

### Rule 2: 2–3 Second Rewarding Completion Loop
- Tapping `✓ Complete` triggers instantaneous feedback:
  - Immediate visual state transition (smooth checkmark fill).
  - Subtle tactile haptic pulse.
  - Overall consistency and progress ring advance immediately.
  - Non-intrusive `+1 Evidence` badge appears.
  - Focus seamlessly advances to the next due practice.

### Rule 3: Tiered Optional Evidence
Evidence capture must never feel like homework:
- **Tier 1 (Normal)**: `✓ Complete` (1-tap, done).
- **Tier 2 (Important)**: `✓ Complete` → Optional `+ Add evidence` (photo/screenshot/quick metric).
- **Tier 3 (Reflection-Worthy)**: `✓ Complete` → Note / voice memo / deep reflection rating.
- No mandatory popups or forced journaling dialogs.

### Rule 4: Consistency Over Streaks
- Streaks create fragility: missing one day resets to zero and causes abandonment.
- VAJRAX tracks **Consistency Rate** (e.g., 82% over 30 days, 5/7 this week). Missing a day drops the rate slightly but never erases weeks of momentum.

### Rule 5: Transparent Pattern Discovery ("Why?")
- No opaque AI black boxes or hallucinations.
- Every insight presents **Raw Data** + **VAJRAX Interpretation** + interactive **"Why?"** drill-down showing exact timestamps and correlation factors.

### Rule 6: Principle Strength Breakdown
- Progress is aggregated into foundational principles:
  - Physical Discipline (91% - Strongest)
  - Deep Work (84%)
  - Self-Respect (78%)
  - Continuous Learning (72%)
  - Reflection (63% - Needs attention)
- Directly answers: *"Which part of your life system is becoming stronger?"*

### Rule 7: Obsidian Dark & Calm Whitespace
- 80% calm whitespace (Obsidian deep dark / Lumina clean slate).
- 20% intentional intensity (Royal indigo / Obsidian gold accents).
- High-legibility typography with negative letter-spacing for premium feel.
- Zero clutter, zero unnecessary decorative elements.

### Rule 8: Automated Metrics First
1. **Automatic**: Silent background resolution via Health Connect (sleep, steps, workouts) and UsageStats (screen time).
2. **Semi-automatic**: Contextual 1-tap quick confirmation widgets and rich notifications.
3. **Manual Fallback**: 1-tap in-app completion with optional evidence.

## 3. The Intervention Engine (Sāma, Dāma, Daṇḍa, Bheda)
When handling friction or skipped habits, the system escalates logically:
* **SĀMA (Align)**: Remind the user of their chosen identity and lower the friction (suggest Minimum goal).
* **DĀMA (Reward)**: Validate success with evidence of character growth.
* **DAṆḌA (Reality Check)**: Provide objective data without shame (e.g., Planned vs Actual).
* **BHEDA (Pattern Discovery)**: Analyze the data to find the hidden variable (e.g., Time of day, prior actions) causing the failure.
