# VAJRAX: Product & UX Rules

This document defines the unshakeable laws of VAJRAX. Every feature must pass these rules before development.

## 1. The Core Philosophy Rules
1. **Progressive Autonomy**: The ultimate goal of VAJRAX is to make itself unnecessary. The app must guide beginners, suggest to intermediates, and quietly reflect for masters.
2. **Zero Nagging**: VAJRAX never competes for attention. Notifications are silent by default, strictly contextual, and never use guilt (e.g., no "We miss you" or "Streak lost").
3. **Proof, Not Points**: Progress is demonstrated through real evidence (completed sessions, photos, notes), not gamified XP, levels, or fire emojis.
4. **Behavior ≠ Motivation**: When a user fails, the app assumes a system failure (friction, environment, timing), not a moral failure (laziness).

## 2. The UX Golden Rules
1. **The 3-Second Rule**: Manual input (logging a habit) must take less than 3 seconds. The default interaction happens via Widgets or Rich Notifications.
2. **Zero Friction Default**: The app must never ask the user to record information the system can automatically know (via Health Connect / UsageStats).
3. **Whitespace is a Feature**: The UI must be 80% calm (dark space) and 20% intensity (gold accent).
4. **The "One Focus" Rule**: The daily screen must only show the *immediate next move*. No endless checklists.
5. **No Failure Red**: Missed habits are neutral. The UI state remains calm, prompting reflection ("What got in the way?") rather than visual punishment.

## 3. The Intervention Engine (Sāma, Dāma, Daṇḍa, Bheda)
When handling user resistance, the system must escalate logically:
* **SĀMA (Align)**: Remind the user of their identity and lower the friction (suggest Minimum goal).
* **DĀMA (Reward)**: Validate success with evidence of character growth.
* **DAṆḌA (Reality Check)**: Provide objective data without shame (e.g., Planned vs Actual).
* **BHEDA (Pattern Discovery)**: Analyze the data to find the hidden variable (e.g., Time of day, prior actions) causing the failure.
