# HabitFlow — User Flows

## 1. First-Time User

Launch → Welcome → Choose Goals → Choose Template → Preview → Customize → Activate Tracker → Today's Plan.

## 2. Select Default Template

Templates → Category → Template Detail → Preview Habits → Use Template → Personal Copy Created → Customize → Activate.

## 3. Customize Template

Personal Tracker → Edit → Add/Edit/Remove Habit → Configure Time → Configure Duration → Configure Frequency → Configure Reminder → Save.

## 4. Daily Completion

Home → Today's Plan → Current Habit → Tap Complete → Persist Log → Update Progress → Show Next Habit.

## 5. Quick Widget Completion

Home Screen Widget → Tap Complete → Persist HabitLog → Recalculate Daily Progress → Refresh Widget → Show Next Habit.

The app should not require a full application launch for normal completion.

## 6. Reschedule Habit

Home → Habit → Move → Select New Time → Confirm → Update Today's Occurrence → Keep Historical Data.

## 7. Skip Habit

Home → Habit → Skip → Optional Reason → Confirm → Mark Occurrence Skipped → Exclude according to analytics rules.

## 8. Weekly Review

Progress → Weekly Review → Completion Summary → Best Consistency → Attention Areas → Reflection → Adjust Routine → Save.

## 9. Monthly Review

Progress → Monthly → Calendar → Completion Trend → Habit Breakdown → Goal Progress → Monthly Reflection.

## 10. Goal Flow

Goals → Create Goal → Define Target → Select Supporting Habits → Save → Track Goal Progress.

## 11. Missed Habit Recovery

Habit becomes overdue → Recovery state → Complete Today / Move / Skip / Record Reason → Save → Update analytics.

## 12. Template Personalization

Optional onboarding questions:
- Wake-up time.
- Work/study start time.
- Available morning time.
- Preferred exercise time.
- Primary goal.
- Preferred reminder style.

System generates a suggested schedule → User reviews → User confirms.
