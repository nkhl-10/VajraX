# HabitFlow — Screen Specifications

## Navigation
Bottom navigation:
1. Home
2. Habits
3. Progress
4. Templates
5. Profile

## Screen 01 — Onboarding
Purpose: Establish user intent and personalize template recommendations.

Components:
- Welcome headline.
- Goal selection.
- Routine preferences.
- Wake-up time.
- Available time.
- Continue CTA.
- Skip optional personalization.

States:
- Initial.
- Selection.
- Validation.
- Completed.

## Screen 02 — Template Library
Components:
- Search.
- Category chips.
- Template cards.
- Habit count.
- Estimated daily duration.
- Preview CTA.
- Use Template CTA.

## Screen 03 — Template Detail
Components:
- Template name.
- Description.
- Recommended-for label.
- Habit timeline.
- Category labels.
- Duration.
- Use Template CTA.

## Screen 04 — Customize Tracker
Components:
- Habit list.
- Add habit.
- Edit.
- Delete/archive.
- Reorder.
- Schedule.
- Reminder.
- Save.

## Screen 05 — Today's Plan
Primary daily screen.

Sections:
- Greeting/date.
- Daily completion percentage.
- Progress bar.
- Current habit.
- Upcoming habits.
- Completed habits.
- Pending habits.
- Quick actions.

Primary action:
- Complete.

Secondary actions:
- Move.
- Snooze.
- Skip.
- Add note.

## Screen 06 — Habit Detail
Components:
- Habit name.
- Category.
- Schedule.
- Target.
- Reminder.
- Current streak.
- Completion history.
- Edit CTA.

## Screen 07 — Calendar History
Components:
- Month selector.
- Calendar.
- Daily completion indicator.
- Selected-day habit list.
- Completion summary.

## Screen 08 — Weekly Progress
Components:
- Completion percentage.
- Daily trend chart.
- Habit breakdown.
- Streaks.
- Most consistent habits.
- Attention areas.
- Weekly reflection.

## Screen 09 — Monthly Progress
Components:
- Monthly completion.
- Calendar heatmap.
- Weekly trend.
- Habit comparison.
- Goal progress.
- Monthly reflection.

## Screen 10 — Goals
Components:
- Goal list.
- Goal progress.
- Supporting habits.
- Create goal.
- Edit goal.

## Screen 11 — Templates
Same functional area as library, including My Templates and Default Templates.

## Screen 12 — Profile/Settings
Components:
- Profile.
- Notifications.
- Theme.
- Data export.
- Backup.
- Privacy.
- Delete data.

## Screen 13 — Android Widget
Compact:
- Today's completion.
- Current/next habit.
- Complete action.

Medium:
- Daily progress.
- Current habit.
- Next 3 habits.
- Quick complete.

Large:
- Progress.
- Current habit.
- Upcoming habits.
- Streak.
- Quick actions.

## Screen States
Every screen must define:
- Loading.
- Loaded.
- Empty.
- Error.
- Offline.
- Disabled.
- Success feedback.
