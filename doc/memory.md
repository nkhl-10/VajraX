# VAJRAX: Project Memory & Knowledge Base

## Project State
* **Current Phase**: Documentation and Architecture Planning.
* **Goal**: Establish a rock-solid product vision, UI/UX philosophy, and technical architecture before writing the first line of code.

## Core Tenets (The "Why")
1. **The Knowledge Gap**: People read endless self-help books but change nothing. VAJRAX exists to bridge the gap between *consuming* knowledge and *living* it.
2. **The Tracker Chore**: Current habit apps are exhausting. They nag, they guilt-trip, and they force manual entry. VAJRAX exists to be a silent, intelligent companion that works in the background.
3. **Behavior ≠ Motivation**: VAJRAX operates on the psychological truth that failure is usually a system problem (friction, environment) rather than a character flaw.

## The 7-Stage Progression
We are building a system that moves users through:
`Self-Respect -> Independence -> Competence -> Boundaries -> Calmness -> Value -> Presence`

## Key Product Decisions Made
* **Brand Name**: VAJRAX (Symbolizing unbreakable discipline and clarity).
* **Design Language**: Obsidian Dark Mode + Glassmorphism + Minimal Gold Accents. (Premium, calm).
* **Intervention Model**: Sāma (Align), Dāma (Reward), Daṇḍa (Reality Check), Bheda (Pattern Discovery).
* **Tech Stack**: Android Native, Kotlin, Jetpack Compose, Room, Health Connect.

## What Not To Build
* A gamified RPG with XP and avatars.
* A notification-heavy nagging machine.
* A complex data dashboard for the home screen.
* A system that punishes broken streaks.
