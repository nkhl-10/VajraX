# VAJRAX Design System & UI/UX Guidelines

## 1. Brand Identity & Design Philosophy
**Brand Idea**: *VAJRAX — Build yourself.*
**Design Feeling**: Powerful but not aggressive. Premium but not flashy. Minimal but not empty. Spiritual but not religious. Gen-Z but not childish.
**The Ultimate Goal**: "A private room for becoming stronger." The stronger the user becomes, the quieter VAJRAX becomes.

## 2. Core Visual Stack: "VAJRAX Morphism"
The aesthetic is a hybrid of Glassmorphism, soft Neumorphism, and strict Minimalism.

### Visual Emphasis:
* **60% Glassmorphism**: Used for overlay layers (e.g., Today's main mission card, Path screens). `rgba(255,255,255, 0.05)` with 16–24dp blur.
* **20% Soft Neumorphism**: Used *only* for interactive objects like the primary `START` button (subtle depth, soft shadow).
* **10% Minimalism**: Massive use of whitespace. "Whitespace is a feature."
* **10% Vajra Accent**: Metallic gold highlights used sparingly to indicate extreme importance or achievement. "Depth indicates importance."

## 3. Color System
A dark-first design that prioritizes calm and focus.

### Base Colors (Obsidian)
* **Primary Background**: `#0B0D0F`
* **Secondary (Charcoal)**: `#14171A`
* **Elevated Surface (Surface 1)**: `#1B1F23`
* **Glass Surface (Surface 2)**: `rgba(255,255,255,0.05)`

### Typography Colors
* **Primary Text**: `#F5F5F2` (White)
* **Secondary Text**: `#A7AAAE` (Light Gray)
* **Muted Text**: `#6F747A` (Dark Gray)

### Accents & State
* **Primary Accent (Vajra Gold)**: `#D6A84F` (Represents achievement, value, mastery).
* **Success**: `#73A889` (Calm green, not neon).
* **Warning**: `#C89A55` (Muted orange/gold).
* **Error**: `#B86B6B` (Muted red, never aggressive).

### Light Mode Fallback
* **Background**: `#F5F3EE` (Warm off-white).

## 4. Typography & Shape
* **Primary Font**: **Manrope** (Clean, modern, premium personality).
* **Corners (Radii)**: Cards `20dp`, Buttons `14–16dp`, Sheets `28dp`.

## 5. Animation & Iconography
* **Animation**: Communicate *state*, not entertainment. Avoid XP explosions.
* **Iconography**: Minimal line icons (24dp grid).
* **Logo Concept**: Abstract, minimal geometric mark combining **V + X + Vajra**.
